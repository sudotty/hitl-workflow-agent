# Demo Positioning

This project is a portfolio demo for business workflow automation.

The demo should show a simple request moving through four stages:

1. Read the request.
2. Extract the important fields.
3. Check the workflow rules.
4. Send the result to a human reviewer.

The value is not full autonomy. The value is reducing manual preparation while keeping the final decision reviewable.

The interviewer should understand three things:

- The workflow is concrete.
- The system has boundaries.
- The result can be inspected by a human.
